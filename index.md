## Latest Guide

### Configuring a TP-Link TD-W8968 as an Access Point for JioFiber

In my first guide, I explain how I converted an older TP-Link modem-router into an access point for a JioFiber connection.

The process included:

- Understanding router mode and access-point mode
- Identifying DHCP and IP-address conflicts
- Resolving a `169.254.x.x` address
- Changing the TP-Link management IP
- Disabling the TP-Link DHCP server
- Testing Wi-Fi and Ethernet connectivity
- Creating one unified `192.168.29.x` network
